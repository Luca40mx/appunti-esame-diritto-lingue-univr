# Appunti per l'esame di Diritto — Lingue per il turismo e il commercio internazionale (UniVR)

Dispense **non ufficiali**, scritte a partire dagli appunti delle lezioni e non riviste dal docente. Il corso è in tre parti: per ora ci sono i capitoli 1–6 della Parte 1.

Per scaricare tutto: **Code → Download ZIP**.

## Struttura

```
01_dispense/parte_1/
  word/                    i capitoli in Word: sono i file da studiare
  00_indice.md             l'indice della Parte 1
  00_filo-rosso.md         la mappa della Parte
  01_…md, 02_…md, …        i capitoli in Markdown (il testo da cui nascono i Word)
  punti_da_verificare.md   le imprecisioni degli appunti, con la versione verificata
  immagini/                le figure dei capitoli
  audit/                   i controlli di completezza dei capitoli
02_ripasso/
  word/ripasso.docx        il ripasso di tutti i capitoli: definizioni, schemi, domande d'esame
  ripasso.md               lo stesso ripasso in Markdown
  glossario.md             i termini tecnici in ordine alfabetico
  articoli-citati.md       gli articoli di legge citati
```
